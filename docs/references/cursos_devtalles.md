### 2. .NET Backend: .NET Core, SQL Server y seguridad JWT

![.NET Backend: .NET Core, SQL Server y seguridad JWT](https://import.cdn.thinkific.com/643563/7c18RVDvTFezQ4VL9JeM_NET-DEVTALLES.jpg)

- **URL Oficial:** [https://cursos.devtalles.com/courses/NET-Backend](https://cursos.devtalles.com/courses/NET-Backend)
- **Duración:** 11 horas, 159 lecciones
- **Instructor:** Teddy Paz

#### Descripción
Construye desde cero una API RESTful profesional en .NET para un e-commerce real. Aprende sobre JWT, Entity Framework, control de acceso, subida de imágenes, cache, versionado y despliegue en la nube.

#### Conocimientos Previos / Requisitos
- Tener conocimientos básicos de programación (estructuras de control, variables, métodos, clases).
- Haber trabajado previamente con C# o completado un curso introductorio.
- Conocimientos básicos sobre HTTP y JSON.
- Visual Studio Code instalado y configurado con .NET 8.
- Acceso a internet para instalar paquetes NuGet y realizar pruebas con herramientas externas como Postman.

### 5. Angular + Sockets: Aplicaciones en tiempo real con Bun
